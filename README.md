### Como trabalho nos repositórios

- **A regra mora no banco, não no formulário.** Validação no servidor e no banco, pra valer inclusive quando alguém chama a API direto.
- **Privacidade tratada como requisito.** Os projetos que foram para cliente têm dados de contato, fotos e hashes de senha removidos **inclusive do histórico** (`git filter-branch`), com autoria, mensagens e datas preservados. As credenciais dos dumps de demonstração são hashes públicos, não senhas reais.
- **Limite declarado em vez de esconder.** Cada README tem uma seção "o que ainda não está pronto": testes que não existem, métricas que ainda não há, o que ainda é protótipo.
